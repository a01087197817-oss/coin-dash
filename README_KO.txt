COIN DASH 앱 패키지
==================

파일 구성
- index.html      게임 본체
- manifest.json   앱 이름/아이콘/설치 화면 설정
- sw.js           앱 파일 캐시 및 오프라인 실행 지원
- icons/          앱 아이콘

중요
이 패키지는 설치 준비가 끝난 PWA 웹앱 파일입니다. 보안상 브라우저의 설치형 앱 기능은 HTTPS 주소(또는 PC의 localhost)에서만 작동합니다. ZIP을 풀고 index.html을 파일 탐색기에서 바로 여는 것만으로는 홈 화면 설치가 활성화되지 않을 수 있습니다.

가장 쉬운 배포 방법: GitHub Pages
1. PC에서 ZIP 압축을 풉니다.
2. GitHub에 로그인하고 새 저장소(repository)를 만듭니다. 예: coin-dash
3. 압축을 푼 폴더 안의 파일과 icons 폴더를 저장소 최상위(root)에 업로드합니다. index.html, manifest.json, sw.js가 같은 위치에 있어야 합니다.
4. 저장소 Settings → Pages로 이동합니다.
5. Build and deployment에서 Deploy from a branch를 선택하고, branch는 main, folder는 /(root)로 설정한 뒤 Save를 누릅니다.
6. 배포가 완료되면 표시된 https://...github.io/... 주소를 엽니다.

안드로이드 휴대폰 설치
1. 위 HTTPS 게임 주소를 Chrome으로 엽니다.
2. 브라우저 메뉴(⋮)에서 '앱 설치' 또는 '홈 화면에 추가'를 선택합니다. 메뉴 문구는 기기/브라우저에 따라 다를 수 있습니다.
3. 설치한 COIN DASH 아이콘을 눌러 실행합니다.
4. 최초로 온라인 상태에서 한 번 열어 두면 서비스 워커가 파일을 캐시합니다. 이후 오프라인 실행은 브라우저/기기의 캐시 정책에 따라 달라질 수 있습니다.

PC 설치
- Chrome 또는 Edge에서 HTTPS 게임 주소를 엽니다.
- 주소창 오른쪽의 설치 아이콘이 보이면 누르거나, 브라우저 메뉴에서 '앱 설치'를 선택합니다.
- 설치 메뉴가 보이지 않으면 페이지를 새로고침하고 잠시 기다리거나 브라우저의 사이트 메뉴를 확인합니다.

테스트
- 먼저 HTTPS 주소에서 게임을 시작해 이동/점프/공격/상점이 정상인지 확인합니다.
- 브라우저 개발자 도구 Console에서 오류가 없는지 확인할 수 있습니다.
- 업데이트 후 캐시가 오래 남아 있으면 페이지를 새로고침하거나 사이트 데이터를 지운 뒤 다시 엽니다.

참고
- 이 패키지는 Google Play에 등록된 APK가 아닙니다. Play 스토어에 올릴 APK가 필요하면 Capacitor 같은 도구로 별도 Android 프로젝트를 만든 뒤 Android Studio에서 빌드해야 합니다.
- GitHub Pages 공개 저장소에 업로드하면 게임 파일이 공개됩니다. 비밀번호나 개인정보를 파일에 넣지 마세요.
